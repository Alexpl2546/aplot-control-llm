Read-only проверка live SQLite подтверждает три профиля и целостность базы; SHA-256 всех трёх native-конфигураций совпадает с предыдущей настройкой. Общие legacy-поля KV/GPU llama.cpp скрыты для Strata, чтобы карточки не показывали ложные q8_0 и GPU layers.

## Hugging Face и llama.cpp

Hugging Face — общий каталог репозиториев разных авторов. Начальная выдача показывает популярные модели, а три Qwen-рецепта являются быстрым стартом. Добавлены настоящая cursor-пагинация «Показать ещё», сортировка и режим всех GGUF без обязательной отметки приложения llama.cpp. Поиск не ограничен готовыми рецептами. Разрешение выбранного репозитория по-прежнему проверяет полный набор shards и предлагает отдельный mmproj.

Ответ IPC поиска теперь `{ items, nextCursor }`. Необязательные поля модели: `parameterCount`, `contextLength`, `sizeBytes`, `architecture`, `baseModel`, `license`, `description`. Они берутся из метаданных HF, а не вычисляются по названию. Размер на карточке — ориентир одного варианта из HF; точный полный набор показывается после выбора квантования. Отсутствующие данные отмечаются прочерком или предложением выбрать GGUF. Переход на следующую страницу извлекает только cursor с разрешённого endpoint HF; произвольные URL не запрашиваются.

Первичные источники API: [HF Hub API](https://huggingface.co/docs/hub/api), [HfApi list_models](https://huggingface.co/docs/huggingface_hub/package_reference/hf_api#huggingface_hub.HfApi.list_models). Проверен настоящий ответ `/api/models`, затем Rust read-only тест подтвердил метаданные и следующую страницу: 3+3 модели без скачивания весов.

## Strata и папки

Каталог по-прежнему читается из установленного Strata; набор поддерживаемых моделей не сокращён. Карточки перестроены в сетку с кратким описанием квантования, возможностями, загрузкой комплекта и оценкой памяти. Повторяющиеся инструкции, английские fits/tight и длинные служебные пояснения убраны; дополнительные сведения раскрываются по «Подробнее».

Папка по умолчанию — `<installation_root>/models/llama` либо `models/strata`. Для standalone EXE без общей структуры используется его папка. Переключение движка сохраняет раздельные ручные пути в текущем окне. Общая GGUF-загрузка использует llama, подготовка Strata — strata. Существующие каталоги не переносятся и не удаляются. На этом ПК это `C:\Dev\Aplot-Control-LLM\models\llama` и `C:\Dev\Aplot-Control-LLM\models\strata`.
