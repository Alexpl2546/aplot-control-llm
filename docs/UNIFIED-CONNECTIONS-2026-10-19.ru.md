# Единые подключения и агенты: первый этап внедрения

Изменения внесены в существующее приложение Aplot Control LLM, версия 0.8.2. Архитектура Tauri/React и адаптер Hermes сохранены. Основание: [анализ Team Room](TEAM-ROOM-ANALYSIS-2026-10-19.ru.md).

## Что реализовано

- Общий раздел «Подписки и подключения»: один вход ChatGPT для обычного чата и Codex CLI. Codex использует подключение приложения через официальный механизм custom Responses provider; отдельный вход Codex из интерфейса убран.
- Claude Code как третий агент рядом с Hermes и Codex. Обычный чат Claude работает через тот же официальный CLI с отключёнными инструментами. Авторизацией Claude управляет CLI в отдельном каталоге Aplot; приложение не извлекает токены из сторонних установок.
- Каталоги моделей привязаны к подключению. Смена аккаунта сбрасывает данные предыдущего подключения. Нативные идентификаторы сессий сохраняются вместе с типом агента и аккаунтом для восстановления совместимых сессий.
- Потоковые ответы, инструменты, запросы разрешений, вопросы пользователю, отмена и данные контекста Claude переведены в общий протокол агентной среды. Ограниченный режим задаётся средствами CLI, а не только текстовой инструкцией.
- «Передать задачу»: редактируемый контекст передаётся в отдельную задачу выбранного агента. Передача создаёт черновик, запуск остаётся явным действием пользователя.
- Очередь следующих сообщений с возможностью удаления и продолжения после остановки. После ошибки автоматического повторного запуска нет.
- Доска задач по состояниям и отдельные карточки дочерних агентов из событий CLI. Их ответы не смешиваются с основным ответом.
- Установщик дополнен выборочным модулем Claude Code, проверкой контрольных сумм и необязательной установкой Git Bash. Лицензии показываются для выбранных компонентов и зависимостей.

## Проверки

- 397 тестов TypeScript/интерфейса в 66 файлах.
- 167 модульных тестов Rust и один тест Windows activation; семь ранее отключённых тестов остаются ignored.
- Проверки типов, статических связей, локализации и документации пройдены.
- 26 проверок политики установщика и тесты модульной установки PowerShell пройдены.
- Официальный Claude Code 2.1.292 скачан с проверкой SHA-256. В отдельном пустом профиле проверены версия, справка авторизации и обмен initialize с получением каталога моделей. Запросы модели не отправлялись.
- В запущенном приложении проверены общий раздел подключений, агентная среда, доска задач и окно передачи контекста. Использовался отдельный тестовый каталог данных; пользовательские проекты и авторизации не использовались.

## Практические ограничения

Вход в реальные аккаунты и генерация ответов по подпискам в этой среде не проверены. Их необходимо проверить после авторизации пользователя. Доступность моделей и лимитов зависит от официального сервиса и плана; отсутствие данных лимитов показывается как неизвестное значение, а не как выдуманный процент.

Голосовой ввод в облачных адаптерах пока не подключён; существующая диктовка Hermes сохранена. Карточки дочерних агентов показывают нативные события, отдельного управления каждым дочерним процессом пока нет. Два чата рядом, удалённые компьютеры и мобильный доступ из последующих этапов анализа Team Room в эту сборку не входят.

Claude Code устанавливается отдельно и работает по условиям Anthropic. Поддержка официального CLI не означает наличие универсального API подписки Claude или гарантии доступа любого тарифа.

## Как начать

1. Обновить приложение новым установщиком; при необходимости выбрать Codex CLI и/или Claude Code в компонентах.
2. Открыть «Чат → Подписки и подключения» и подключить нужный аккаунт.
3. Для обычного диалога выбрать ChatGPT или Claude. Для инструментов открыть «Агентная среда», создать задачу и выбрать агента, модель и режим доступа.

Релизная сборка Tauri/NSIS завершена успешно. Готовый установщик этого этапа размещён в `releases/unified-agents-2026-10-19`. Версия приложения остаётся 0.8.2, поэтому установщик может предложить восстановление/изменение текущей версии вместо обновления по номеру.
