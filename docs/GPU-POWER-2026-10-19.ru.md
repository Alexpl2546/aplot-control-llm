# Показания потребления GPU

На тестовом ноутбуке было показано `38.29 / 0 W`. Текущее потребление и лимит — разные измерения; недоступный лимит раньше ошибочно превращался в ноль. Сообщённые 131 Вт пока не подтверждены одновременным замером драйвера на этом компьютере. Значение не подставляется по названию видеокарты или ответу ChatGPT.

Изменения:

- Приоритет у `power.draw.instant`, затем `power.draw.average`, затем совместимого `power.draw` для старых драйверов. Если расширенный запрос не поддерживается, используется старый набор полей.
- В интерфейсе отдельно показаны потребление и действующий лимит (`enforced.power.limit`). Максимальный допустимый, заводской или программно запрошенный лимит не выдаются за действующий.
- Подпись отличает мгновенное значение от среднего за секунду; показания — данные драйвера NVIDIA. Недоступные значения сериализуются как null и показываются прочерком. В графиках они оставляют пропуск. Реальное измерение 0 Вт остаётся допустимым.
- Те же правила применяются в мониторе бенчмарка.

Документация NVIDIA: https://docs.nvidia.com/deploy/nvidia-smi/index.html (GPU Power Readings). Отдельные мгновенный и средний запросы добавлены в ветке 530; поддержка старых драйверов сохранена.

Для проверки на самом тестовом ПК можно запустить в PowerShell файл `check-gpu-power.ps1` из папки сборки. Он только читает показания NVIDIA, ничего не меняет в настройках видеокарты и не запускает нагрузку. За 10 секунд сохраняет `gpu-power-report.json` рядом со скриптом; снимки содержат время, имя и UUID GPU, версию драйвера, потребление и доступные лимиты. Так можно сопоставить показатели с другой утилитой в один момент. Пример запуска:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\check-gpu-power.ps1
```

Проверки: 368 frontend-тестов, 158 Rust-тестов (7 внешних пропущены), валидация переводов и команд, типизация. Сняты реальные мгновенное и среднее значения с локальной RTX 5080; сопоставление с RTX 3070 Ti Laptop на другом компьютере ещё не выполнено.
