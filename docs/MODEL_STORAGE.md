# Хранение моделей

Папки моделей выбираются в приложении. Библиотека объединяет настроенные каталоги, зарегистрированные установки и файлы, на которые ссылаются сохранённые профили. Веса, среды движков и пользовательская база не включаются в Git.

## Каталоги

В переносимой установке библиотека располагается рядом с приложением в `models`. Установленная версия также определяет корень по каталогу `components` и сведениям об установке. Поиск включает существующие `models/llama`, `models/llama.cpp` и `models/strata`; импорт GGUF использует `models/llama`. Другие каталоги можно добавить в настройках.

Точные правила определения путей находятся в [db.rs](../app/src-tauri/src/db.rs) и [model_library.rs](../app/src-tauri/src/model_library.rs). Пути локальной рабочей машины не являются настройками для других установок.

## Загрузка

Для llama.cpp загрузчик получает полный выбранный GGUF-вариант из публичного Hugging Face Hub. Для Strata используется каталог установленного движка и подготовка необходимых файлов. Дополнительный шард и проектор изображений не являются самостоятельными моделями.

Незавершённые GGUF-загрузки хранятся в `.aplot-staging` внутри выбранного каталога и не попадают в библиотеку. Проверенный набор публикуется целиком; история установки сохраняется в SQLite. См. [контракт загрузок](../app/docs/ru/modules/model-downloads.md).

## Удаление

Удаляйте модели через библиотеку приложения: она строит план удаления с учётом общих файлов и зависимостей. Не удаляйте общий tokenizer, проектор или веса вручную, если их используют другие конфигурации. Остановите использующий модель сервер перед удалением.

[Каталог артефактов](../app/docs/ru/modules/models.md) описывает зависимости; реализация удаления находится в [model_removal.rs](../app/src-tauri/src/model_removal.rs).
