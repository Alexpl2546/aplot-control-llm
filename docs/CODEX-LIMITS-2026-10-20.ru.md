# Лимиты Codex: авторизация по профилям — 20 октября 2026

## Подключение

Обновите Aplot сборкой `releases/codex-limits-2026-10-20`, откройте **Настройки → Подписки и подключения**, найдите подключённый профиль ChatGPT и нажмите **Подключить лимиты Codex**. В браузере подтвердите тот же аккаунт. При необходимости сначала установите Codex CLI в разделе компонентов.

Это дополнительное подтверждение требуется для лимитов: существующий вход Sign in with ChatGPT обслуживает чат и агента через Responses API, а лимиты читает официальный аккаунт Codex. Приложение не пытается использовать токен Responses как токен Codex. Профиль в Aplot остаётся один. После подтверждения лимиты обновляются автоматически и показываются под соответствующим аккаунтом в боковой панели. После успешного входа приложение выводит своё окно на передний план.

Можно отменить вход или отключить только лимиты, сохранив работу чата. «Отключить» весь профиль приостанавливает его работу и процессы, сохраняя авторизацию; выход и удаление профиля также выполняют выход из связанного аккаунта Codex. Для завершения выхода из сохранённой авторизации Codex его CLI должен быть доступен.

## Реализация

- Новый native broker `codex_limits.rs` использует только штатные account/login/start, account/login/cancel, account/read, account/logout и account/rateLimits/read. Он не предоставляет запуск инструментов или inference.
- Отдельный CODEX_HOME для каждой пары профиль/connectionId; токены остаются у Codex в Windows credential store (keyring). Переход на открытый auth.json отключён. Авторизация внешнего Codex Desktop/CLI не копируется и не меняется.
- Перед каждым запросом лимитов сверяются тип аккаунта ChatGPT и email подключённого профиля. Несовпадение вызывает выход из новой авторизации и понятную ошибку. Профиль проверяется повторно после асинхронных запросов.
- Отмена, ошибки и тайм-ауты не превращаются в успешное подключение. Смена исполняемого файла и завершение Aplot закрывают только принадлежащие приложению процессы.
- Кэш и ошибки изолированы по connectionId. Поздний ответ после отключения не возвращает старые лимиты. Новое подключение может начать запрос, не дожидаясь старого. Автоматическое обновление учитывает задержку между запросами и увеличивает паузу после сетевых ошибок.
- Боковая панель остаётся компактной: аккаунт и его лимиты. Кнопки управления находятся внутри существующего окна настроек.

## Проверка и ограничения

Проверены frontend-тесты маршрутизации, изоляции аккаунтов, отключения/повторного подключения и запоздавших ответов, а также native-проверки типа аккаунта и допустимых OAuth-адресов. Установленный официальный Codex CLI проверен в новой пустой среде: initialize проходит, account/read возвращает null, account/rateLimits/read отклоняется без авторизации, auth.json не создаётся. Запросы inference не выполнялись.

В браузерной демосреде проверен блок подключения лимитов. Данные демонстрационные; реальная авторизация пользователя и получение реальных процентов без его входа не проверены. Снимок: ../app/artifacts/codex-limits-ui/connect-limits.png.
