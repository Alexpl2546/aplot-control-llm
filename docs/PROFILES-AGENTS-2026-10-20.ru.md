# Профили, настроенные агенты и интерфейс — 20 октября 2026

## Что изменилось

- Несколько независимых профилей ChatGPT и Claude Code. У каждого своё имя, вход и окружение CLI. Подключение выбирается отдельно для чата или задачи. Новый профиль не переключает текущий по умолчанию.
- Существующие подключения перенесены в профили ChatGPT / Claude без копирования секретов в интерфейс. Новые ChatGPT-секреты защищены Windows DPAPI, Claude авторизуется штатным CLI с отдельным CLAUDE_CONFIG_DIR.
- «Отключить» сохраняет вход и останавливает работу этого профиля; «Выйти» удаляет авторизацию; «Удалить» убирает профиль. Проекты, файлы и история задач сохраняются. Выбранный в задаче удалённый или отключённый аккаунт не подменяется другим.
- После успешного обмена OAuth приложение получает фокус. Страница завершения входа оформлена в стиле Aplot, код убирается из адресной строки этой страницы.
- Настроенные агенты: имя, Hermes/Codex/Claude, модель, профиль подключения или локальный сервер, инструкции и режим доступа. Параметры копируются в задачу; последующее редактирование шаблона не меняет уже созданную задачу.
- Сервер можно сохранить без запуска. Для локального агента можно включить запуск назначенного сервера при старте задачи; агент ждёт готовности и привязывается к фактическому поколению сервера.
- Значки агентов добавлены к выбору агента, задачам и активным сессиям.
- В чате сверху остались Local / ChatGPT / Claude. Профиль, модель, сервер, вложения и навыки находятся у поля ввода.
- Настройки открываются окном с категориями и возвращают пользователя к прежнему экрану. Удалены поиск команд и Ctrl+K.
- Короткие переходы окон, меню, правой панели и разделов. Учитывается системное уменьшение движения. Thinking Orbs отображает подключение, работу, поиск и формирование ответа; используется npm thinking-orbs 0.3.2 (MIT).

## Медиа и навыки

Изображения передаются как изображения, PDF — как документ в облачных подключениях; текстовые файлы и выбранные SKILL.md — как явно добавленный контекст. Навык в обычном чате добавляет инструкции, но не запускает инструменты агента.

Видео разбирается локально на четыре кадра по длительности. Интерфейс прямо сообщает, что звук и остальные кадры не передаются. Поддержка декодирования зависит от WebView2 и кодека; неподдерживаемый файл показывает ошибку до отправки. Полный видео/аудиоввод через SiWC сейчас не поддерживается. Локальный чат использует изображения, если это поддерживает запущенная модель; PDF следует передавать облачному подключению либо извлечь текст/страницы.

## Лимиты

Панели Codex и Claude постоянно раскрыты. Можно выбрать профиль. Проценты отображаются только при наличии настоящих данных.

Codex account/rateLimits/read запрашивается для соответствующего соединения. Текущий единый вход ChatGPT использует SiWC и официальный custom Responses provider для Codex app-server; такой вход может не предоставлять данные лимитов Codex. Это ограничение не устранено: вместо выдуманных процентов показано понятное состояние недоступности. Claude показывает данные rate_limit_event после получения их штатным CLI.

- 406 тестов TypeScript в 67 файлах; типы, статические проверки и документация — успешно.
- 172 модульных теста Rust и один тест Windows activation — успешно, 7 прежних специальных проверок пропущены.
- Установщик: 26 встроенных проверок при сборке.
- Проверены открытие и закрытие модального окна настроек, переключение его разделов и новое расположение элементов чата. Проверка UI выполнялась в отдельном экземпляре с синтетическими проектами и без настоящих авторизаций. Одновременные запросы к нескольким реальным аккаунтам и новые OAuth-входы в этой проверке не выполнялись.
