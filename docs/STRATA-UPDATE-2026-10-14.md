# Обновление Strata — 14 октября 2026

Рабочая установка `engines/strata` обновлена с **0.1.43.1 до 0.1.44.1**: [официальный релиз](https://github.com/Niko1221/Strata/releases/tag/v0.1.44.1), коммит `296b59d2f73c8f04a805df29c2fa97655adace78`.

Установлены официальный CUDA 13 архив для Windows x64, оба EXE и новый `strata_kq.dll`. Опубликованный и фактический SHA-256 архива совпадают: `a29bda047f440e6d2ce1649306c3a7047ba35df5a032097c7509d4494fa2b448`. Обновлены Python-сервер и остальные исходники тега. Зависимости Python не изменились; `pip check` прошёл.

Локальные изменения `serve/server.py`, `serve/test_server.py`, `setup.py`, README и DETAILS перенесены трёхсторонним слиянием без конфликтов. Сохранены точный подсчёт токенов, `/openapi.json`, TTFT и локальный каталог моделей в setup. [Патч Aplot](../integrations/strata/aplot-api.patch) пересоздан на новом теге; он применяется к чистым исходникам и воспроизводит установленные файлы сервера и теста.

Три пользовательские конфигурации `strata-*.json` и SQLite база Aplot сохранили SHA-256. Все 39 файлов весов и компонентов больше 100 МиБ в `models` сохранили размер и NTFS file ID. Профили, пути моделей и настройки памяти не изменялись.

## Проверки

- `python -m unittest discover -s serve -t .`: 786 тестов, 774 прошли, 12 пропущены; ошибок нет (288,5 с).
- `cargo test strata::tests --lib --locked`: 2 теста адаптера Strata прошли.
- `npm run build`: TypeScript и сборка Vite прошли; остаются предупреждения Vite о размере чанков и смешанном импорте Tauri window.
- Реальная Qwen IQ3_S загружена на RTX 5080 с лимитом контекста 131072; `/v1/status` подтвердил версию движка `0.1.44.1`.
- Chat Completions вернул ответ `4` на `2 + 2`; точный API подсчёта и `usage.prompt_tokens` показали 23 входных токена.
- `/openapi.json` и подсчёт токенов требуют ключ; без него возвращают HTTP 401. TTFT присутствует в завершённом запросе. Web UI и `/metrics/prometheus` доступны.

Проверка генерации использовала отдельную временную копию конфигурации: RAM экспертов 24 ГиБ, резерв VRAM 2048 МиБ, KV resident 32768. Это проверка загрузки и короткого запроса, не заполненного контекста или скорости пользовательского профиля. Предыдущие результаты измерений на 0.1.43.1 остаются историческими.
