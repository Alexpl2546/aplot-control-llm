# Aplot Control LLM

Текущая версия — **0.10.6**. Описание возможностей, установка и сборка: [README](README.md) · [English](README.en.md).

| Каталог | Назначение |
| --- | --- |
| `app/src/` | Интерфейс React и TypeScript |
| `app/src-tauri/` | Rust, команды Tauri и установщик Windows |
| `app/tests/`, `app/e2e/` | Автоматические проверки |
| `app/scripts/` | Сборка, валидация и подготовка лицензий |
| `app/docs/ru/`, `app/docs/en/` | Архитектура и контракты модулей |
| `integrations/strata/` | Дополнения API Strata |
| `.github/` | CI и выпуск релизов |

Команды разработки выполняются из `app`:

```powershell
npm ci
npm run tauri:dev
```

`npm run dev` открывает браузерную демонстрацию. Управление настоящими процессами доступно в настольной версии.

[Документация](docs/README.md) · [Проверки](app/docs/TEST_PLAN.md) · [История версий](CHANGELOG.md).

Модели, установленные компоненты, настройки, базы данных и результаты сборки хранятся вне отслеживаемых исходников. Каталоги для моделей выбираются в приложении; переносить их при обновлении исходников не требуется.
