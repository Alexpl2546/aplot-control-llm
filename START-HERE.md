## Запуск и проверки

```powershell
cd C:\Dev\Aplot-Control-LLM\project\app
npm run tauri:dev
```

Проверки исходников: `npm run verify:source`, `npm run verify:docs`, `npm run verify:modules`, `npm test`. Сборка интерфейса: `npm run build`. Для установки зависимостей на другой машине выполните `npm ci`.

## Локальные ресурсы

Веса, установленные движки и рабочая база физически сохранены в исходных каталогах `C:\Dev\Aplot-Control-LLM\models`, `engines`, `data`. Одноимённые папки здесь — ссылки Windows junction. Так сохраняются абсолютные пути профилей, сред Python и общие файлы моделей.

Кэш Cargo, npm-зависимости, результаты сборки и отчёты находятся рядом в `C:\Dev\Aplot-Control-LLM\local`. Ссылки `app/src-tauri/target`, `app/src-tauri/gen`, `app/node_modules`, `app/dist`, `app/artifacts` сохраняют ожидаемые пути инструментов. Эти локальные данные исключены из Git. Самостоятельно переносимая часть проекта — исходники и документация; локальные ссылки привязаны к этой машине.

Предыдущие версии, резервные копии, прототипы и старые отчёты перенесены в `C:\Dev\Aplot-Control-LLM\history`. Журнал перемещений и исходный инвентарь находятся в `history/organization-2026-10-22` относительно общей папки.

Git-репозиторий находится здесь, в `project/.git`. В общей папке оставлен файл-указатель `.git`, поэтому команды Git работают из обоих расположений. Все существовавшие локальные изменения сохранены.
