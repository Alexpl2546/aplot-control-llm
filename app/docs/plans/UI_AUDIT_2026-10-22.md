# Проверка интерфейса — 22 октября 2026

Проверены React-интерфейс Aplot Control LLM 0.9.1, браузерные пользовательские сценарии и сборка приложения для Windows. Существовавшие незакоммиченные изменения сохранены.

Исправления:

| Область | Воспроизведённая проблема | Результат |
| --- | --- | --- |
| Размещение страниц | На ширине менее 1280 px закреплённая панель накрывала левую часть содержимого | Закреплённая панель занимает собственную колонку; режим свёрнутого меню сохраняется |
| Настройки | Изменение сохранённого параметра, в том числе генерация API-ключа, сбрасывало черновики остальных полей | Синхронизируются только изменившиеся сохранённые поля |
| Сохранение | Повторный Enter/клик создавал конкурирующие сохранения; ошибки оставались необработанными | Повторные запросы заблокированы, ошибки показаны, введённые данные доступны для повтора |
| Профили | Ошибка выбора/сохранения и отрицательный результат выбора модели не препятствовали дальнейшим действиям | Переход выполняется после успешного результата, конфликтующие операции блокируются |
| Подтверждение | Escape и управление фокусом не работали; крестик и фон отменяли незавершённую операцию | Модальный dialog, циклический Tab, возврат фокуса, блокировка повторного подтверждения и закрытия, ошибка с возможностью повтора |
| Выпадающие списки | После удаления выбранной option или при первой disabled option видимое значение расходилось с данными формы | Значение синхронизировано с фактическим native select |
| Чат | При продолжении диалога история теряла сообщения только с изображением/PDF | Вложения сохраняются в отправляемой истории |
| Новый чат | Кнопка не сбрасывала черновик и вложения до первого сообщения | Черновик и вложения очищаются; чтение вложений защищено от сброса |
| Настройки агента | Пункт «Пользовательский» с пустым value не вызывал смену пресета | Пресет отвязывается с сохранением параметров и черновика; активная сессия защищена |
| Копирование | Недоступный или запрещённый Clipboard API приводил к исключению | Ошибка обработана; блок кода показывает результат копирования и сбрасывает его при обновлении текста |
| Журнал | Очистка на паузе оставляла старые строки; смена сервера показывала прежний снимок | Очищается видимый снимок; смена сервера возобновляет показ его журнала |
| API-документация | Поздний ответ/ошибка предыдущего сервера подменяли текущую документацию | Устаревшие ответы игнорируются, включая переключение на остановленный сервер |
| Валидация | Сообщения показывали шаблоны `{{…}}`, extraArgs ошибочно отмечались как unsupported | Сообщения интерполированы, ложная отметка удалена |
