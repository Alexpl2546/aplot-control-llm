# Исправление путей проектов — 23 октября 2026

Причина ошибки на снимке: сохранённая папка `C:\Dev\Aplot-Control-LLM\app\artifacts\agent-workspace-v2\workspace` отсутствует после переноса исходников в `project`. Папка `C:\Dev\Aplot-Control-LLM\project\app\artifacts\agent-workspace-v2\workspace` существует.

## Изменения

- При загрузке приложения восстанавливается отсутствующий старый путь только внутри собственной папки `app/artifacts/agent-workspace-v2`, если соответствующая папка найдена в `project/app/artifacts/agent-workspace-v2` внутри той же установки. Существующие пути и произвольные пользовательские проекты не меняются. Канонический путь сохраняется с новой ревизией SQLite.
- В настройках проекта путь редактируется вручную или через «Выбрать папку». Сохранение проверяет реальную папку, исключает дубликаты и блокирует смену рабочей папки во время активной сессии.
- Сохраняются ID проекта, задачи, сообщения, черновики, память и назначения агентов. После смены папки сбрасываются идентификаторы прежней сессии и связанные с прежним путём вложения/очередь; новая сессия использует новую папку.
- «Показать в проводнике» сначала сохраняет изменения. Папки открываются непосредственно, файлы выделяются; расширенный префикс Windows нормализуется перед передачей Explorer.
- При ошибке сохранения окно остаётся открытым с возможностью повторить действие. Для недоступной папки показана подсказка выбрать существующую.
