# Диагностика

## API справка не открывается

Проверьте, что выбранный run в состоянии `ready` или `busy`, и что его endpoint отвечает. `fetch_openapi_spec` разрешает только локальный HTTP endpoint для текущих engines; URL с логином, паролем или публичным HTTPS здесь не принимается. Ошибки `401/403` означают отказ в сохранённой авторизации. Встроенная спецификация для части движков является справочной и может отличаться от установленной версии.

## Показан legacy fallback

Fallback означает, что используется старый desktop backend без зарегистрированной `list_runs`; он показывает только прежний runtime snapshot. Текущий backend регистрирует обе manager-команды. Если список загрузился, но target получить не удалось, проверьте ошибку `run_connection` и соответствие его `runId` выбранному запуску. Другие IPC-ошибки отображаются и не маскируются старым состоянием.

## Health, список модели и SSE дают разные результаты

- `unsupported` — endpoint ответил 404/405/501 или вернул формат, которого этот уровень не распознал.
- `failed` — HTTP-ошибка, неверный ID модели, некорректный SSE event, error frame или тайм-аут.
- `cancelled` — пользователь отменил операцию или сменил target.
- `partial` — ни один уровень не завершился ошибкой, но часть проверок не поддерживается.

В проверке перечисляются только HTTP status и безопасное пояснение; response body намеренно не показывается.

## В harness не подключается localhost

Адрес `127.0.0.1` доступен из того же network namespace. Если harness работает в WSL, контейнере или на другой машине, localhost указывает на его собственную среду. Нужен адрес, доступный из окружения harness, и повторная проверка оттуда. Frontend HTTP-check может быть заблокирован CORS даже тогда, когда запрос из среды harness работает.

## Шаблон конфликтует с текущим файлом

Pi/OpenClaw JSON preview не перезаписывает существующий provider ID и сохраняет неизвестные поля на уровне JSON-объекта. При конфликте выберите другой provider ID вручную либо объедините фрагмент вне приложения. YAML для Hermes и DeepSeek Harness даётся как snippet: parser, автоматическое merge и undo для YAML не реализованы.
