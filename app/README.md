# Aplot Control LLM — application source

Инструкции по установке, поддерживаемым движкам и сборке: [README на русском](../README.md).

Installation, supported engines and build instructions: [English README](../README.en.md).

This directory contains the React/TypeScript frontend and Tauri/Rust backend. Run npm commands here. `npm run dev` provides a browser preview with demo data.

```powershell
npm ci
npm run tauri:dev
```

Technical documentation: [architecture](docs/ARCHITECTURE.md), [IPC](docs/IPC_CONTRACT.md), [benchmarks](BENCHMARKING.md), [Windows build](docs/WINDOWS_BUILD.md).
